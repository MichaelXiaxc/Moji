# Bundled fonts

These unmodified fonts are distributed under the SIL Open Font License 1.1. Each directory includes its own original OFL.txt, copyright notices and any Reserved Font Names.

| Directory | Family | Upstream |
|---|---|---|
| noto-sans-sc | Noto Sans SC (Chinese print) | https://github.com/google/fonts/tree/main/ofl/notosanssc |
| ma-shan-zheng | Ma Shan Zheng (Chinese calligraphy) | https://github.com/google/fonts/tree/main/ofl/mashanzheng |
| lato | Lato (Latin print) | https://github.com/google/fonts/tree/main/ofl/lato |
| caveat | Caveat (Latin handwriting) | https://github.com/google/fonts/tree/main/ofl/caveat |

Downloaded 2026-11-03 from the google/fonts repository via its jsDelivr mirror. Original binaries were renamed to font.ttf for uniform local URLs; no font contents were modified. Variable fonts use weight 400 for writing. Fonts load from this application locally, without runtime requests to Google Fonts or a CDN.
